# Changelog

All notable changes to this project are documented in this file.

## 0.2.0 - 2026-08-12

Initial public release prepared for the Home Assistant integration:

- asynchronous local TCP telemetry;
- automatic detection of the supported 1511 and 02B0 protocol families;
- native UDP discovery and bounded private-network analysis;
- local logger and micro-inverter metadata parsing;
- raw alarm words and privacy-safe diagnostic traces;
- physical validation with TSOL-MP3000 and TSOL-MX500.
